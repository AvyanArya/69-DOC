        Settings and setup help
        First time setup
        1. Install Ollama from ollama.com, then run ollama pull llama3.1 once.
        2. Start it with ollama serve (if the Ollama app is already running in your menu bar or tray, it is already serving).
        3. If Jarvis still says Ollama is off, Ollama is probably blocking requests from a local file. Quit Ollama, then start it with OLLAMA_ORIGINS=* ollama serve on Mac or Linux, or on Windows run set OLLAMA_ORIGINS=* then ollama serve in the same Command Prompt.
        4. If Chrome asks to let this page access devices on your local network, click Allow.
        5. Voice input needs Chrome and an internet connection (Chrome sends audio to Google for speech recognition). Allow the microphone when asked.
